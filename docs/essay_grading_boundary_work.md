# 서술형 채점 경계 개선 작업 기록

목표는 확인된 답안 근거로 25점 문항을 채점하고, 시험 전체 60/100점 목표를
일관되게 판단하는 것이다. 기존 A/B/C/D/E 배점과 Topic 승인 계약을 유지한다.

## 수정 전 기준선 (2026-10-28)

공개 합성 문항: 차압식·층류식 유량계의 차압–유량 관계와 적용 조건 비교.

| 답안 | 요구 판정 | 계산 점수 | 최종 점수 | 원인 |
| --- | --- | ---: | ---: | --- |
| 관계와 조건 설명 | SATISFIED 4 | 16.0 | 16.0 | 계산 점수 그대로 |
| 관계만 설명, 조건 생략 | SATISFIED 2, MISSING 2 | 13.0 | 15.0 | `TECHNICALLY_ADEQUATE_SCORE_FLOOR` |
| 관계를 뒤바꿈 | WRONG 2, MISSING 2 | 2.0 | 4.5 | 비어 있지 않은 답안의 하한 |

현재 `canonical_claim_extractor`는 미해결 문장을 `unresolved_spans`로 반환하지만,
`deterministic_primary_grader`는 요구 판정기에 `extraction_complete=True`를
고정 전달한다. 따라서 관련 문장의 해석 실패가 누락으로 간주될 수 있다.
문항별 15점 표시는 전체 60/100점 목표의 참고값이며 문항 과락 규칙이 아니다.

## 순서와 검증 기준

1. 관련 미해결 문장만 보류하고 무관한 문장은 정상 채점을 유지한다. 보류된 핵심
   요구는 합격 확정을 막고 실패 이유를 기록한다.
2. 15점 최소 보장의 제거는 `ESSAY_SCORE_FLOOR_PILOT=1`에서만 시험한다.
   기본 운영 정책은 전문가 범위 회귀가 통과할 때까지 유지한다.
3. 의미 해석 보조는 필요한 문장에만 적용하고 원문 근거·사실 조건을 검증한다.
   검증 불가·제공자 실패 시 보류 상태를 유지한다.
4. 기존 전문가 검토 사례와 8점·15점 경계 사례로 오합격·오불합격을 측정한다.
   전문가 라벨이 없는 답안을 독립 기준으로 사용하지 않는다.
5. 시험 집계는 모든 문항이 완료됐을 때만 전체 60점 판정을 확정한다. 점수를 얻은
   근거와 부족한 요구를 출력한다.
6. 집중 회귀, `validate-all`, 전체 release를 통과한 뒤 운영 환경에서 확인한다.

점수·검증 결과와 남은 한계는 같은 문서에 갱신한다. 개인 세션 데이터는 공개하지 않는다.

## 현재 결과와 출시 경계

- 관련 미해결 문장과 미충족 machine-contract 요구가 연결되면 점수를 잠정값으로
  표시하고, 문항 참고선 도달 여부를 확정하지 않는다. 관련 없는 미해결 문장은
  이 보류를 일으키지 않는다. 이는 독립 LLM 의미 검증이 아니라 안전한 보류 장치다.
- 문항별 15점은 시험 전체 60/100점의 공식 합격 판정이 아니다. 출력 명칭을
  `문항 참고선`으로 바꾸고, 전체 문항이 완료된 경우에만 별도 집계한다.
- 15점 보장을 기본 경로에서 제거한 시험에서는 전문가 검토 48건의 점수 범위
  일치율이 `0.833333`으로 하락하여 기존 최소 `0.85` release gate가 실패했다.
  범위 밖 8건은 `sil_target_operations_issue1`, `sis_lopa_architecture_issue1`,
  `mcdc_vmodel_sil_issue1`, `qtype_qg-da-high-01`, `qtype_qg-ie-high-01`,
  `risk_nyquist_normal_01`, `risk_lead_lag_normal_01`, `risk_lqr_normal_01`이다.
  이 중 어떤 사례가 표면 매칭 실패인지, 전문가 라벨과 충돌하는지는 아직
  독립 재검토되지 않았다. 기준을 낮추거나 라벨을 임의로 바꾸지 않는다.
- `ESSAY_SCORE_FLOOR_PILOT=1`은 비교용이다. 승인된 운영 정책으로 간주하거나
  운영 컨테이너에 설정하지 않는다. 8·15·20점 경계의 독립 검토와 재현성 검증 후
  기본 정책 전환을 판단한다.
- D/E Argon 경로의 정성적 근거 검증·제공자 실패 처리와 3인 독립 평가 여부는
  이번 변경으로 해결됐다고 주장하지 않는다. 현재 세 채점자 결과는 독립
  측정치로 사용할 수 없다.
- 2026-10-28 검증: 집중 pytest `35 passed`, `rubric_manager.py validate-all`
  `ALL VALID`, `PROMOTE_GENERATED=0 scripts/validate_release.sh` 종료 코드 0.
  release의 전용 10회 재현성 검사는 opt-in이라 실행하지 않았다. 검증 중에는
  개인 답안·운영 DB를 수정하지 않았다.

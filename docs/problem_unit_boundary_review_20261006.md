# Problem-unit Topic Pack 경계 검토 (2026-10-06)

## 목적과 범위

문제 단위 Topic Pack 기준을 최근 Chapter 20에서 추가된 Sight Glass, Float,
Bubbler 초안에 적용해 보았다. 이번 기록은 경계 검토이며 기술 내용 승인이나
Pack source 변경이 아니다. 기존 사용자의 미커밋 변경은 그대로 두었다.

## 기준

Topic Pack은 단순히 장치명·교재 절·공식 분류로 묶는 것이 아니라, 실제 문제에서
요구하는 답안 단위와 채점 소유권을 기준으로 한다. 독립 답안, 필수 요구 축, 채점
기준/owner가 서로 다른지 확인한다. 예상 질문 패턴은 검토 보조 자료일 뿐 실제
기출 문항의 존재를 증명하지 않는다.

## 증거 공백

- 세 `model_answer.json`의 `expected_question_patterns`는 현재 초안에 적힌 예상 문장이다.
- 연결된 공식 시험 회차·교시·문항 번호 또는 실제 질문 원문이 세 Pack에서 확인되지 않았다.
- 공개된 [Chapter 20 WordPress 글](https://now0930.pe.kr/wordpress/chapter-20/)의 검색
  내용은 Sight Glass → Float → Hydrostatic → Bubbler → Closed Vessel DP 등을 하나의
  학습 흐름으로 설명한다. 이는 지식 간 연결 근거이지, 해당 기기가 서로 다른 실제 시험
  문항이라는 증거는 아니다. 검색으로 별도 기출 페이지/문항 ID는 찾지 못했으며, 페이지
  본문 직접 열기는 검색 도구의 cache miss로 확인하지 못했다.
- 따라서 신규 Pack 3개를 시험 문제 단위라고 확정하거나, 예상 패턴 수만큼 분리하는
  결정을 내릴 수 없다.

## WordPress 이력 확인 (읽기 전용, 2026-10-06)

비공개 `wordpress_sources.sqlite3`의 산업계측제어기술사 카테고리에서 관련 용어를
검색했다. DB 파일이나 전체 본문을 외부로 공개하지 않았고, 조회는 읽기 전용이었다.

- Sight Glass/Bubbler/Float 등 관련 용어를 본문까지 확장 검색한 결과 5개 글이 걸렸다.
  대부분 Chapter 20 설명 또는 다른 레벨 계기 글이며, 회차·교시·문항 번호가 확인되는
  실제 시험 문제는 없었다.
- 제목을 `level`, `액면`, `수위`로 확장한 결과 직접 관련 제목은 post_id `6301`,
  [수위 측정기 종류](https://now0930.pe.kr/wordpress/%EC%88%98%EC%9C%84-%EC%B8%A1%EC%A0%95%EA%B8%B0-%EC%A2%85%EB%A5%98/)
  한 건이었다. 이 글은 초음파·플로트·가이드로프·정전용량·레이저의 측정방식 안내이며
  기출 질문이나 회차 ID를 담고 있지 않았다. 따라서 Float 원리의 **참고자료**로는
  쓸 수 있지만 독립된 문제 단위의 근거는 아니다.
- 공개 검색도 관련 독립 기출 글을 찾지 못했다. 따라서 현 WordPress 보유자료 범위에서
  이 세 초안에 연결할 실제 기출 ID는 **확인되지 않음**으로 기록한다. 이는 외부 시험
  자료 전체에 해당 문제가 없다는 의미는 아니다.

## 권장 다음 단계

1. 보유자료에서는 대응 기출 ID가 확인되지 않았다. 추후 새로운 시험문제 자료가
   추가되면 각 패턴과 실제 문항 ID·원문을 연결한다. 문항이 없거나 미확인인 경우
   그 상태를 그대로 기록하며 만들어내지 않는다.
2. 실제 문항별로 요구 축, 단독 답안 가능 여부, 점수 판정 근거, 인접 Pack handoff를
   표로 기록한다.
3. 같은 Pack을 유지하려면 통합 답안·공통 owner 근거를, 분리하려면 독립 문항·상이한
   채점 owner/기준 근거를 기록한다.
4. 증거가 모이기 전까지 세 Pack은 draft 상태로 두고 routing/generated source를
   운영 경로에 승격하지 않는다.

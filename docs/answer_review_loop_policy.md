# 문제 출제 → 답안 작성 → 채점 → 모범답안 → 지식 보완 반복 정책

상태: **학습 운영 정책 확정** (2026-11-07). 이 문서는 사용자가 지시한 반복 학습 순서를 정한다. 코드 구현·운영 배포 완료를 뜻하지 않는다.

## 1. 목표와 순서

산업계측제어기술사 준비의 기본 학습 단위는 **문제 1개와 그에 대한 한 번의 답안·채점·복습 주기**다. 아래 순서를 지킨다.

```text
① ChatGPT 문제 출제 (문제 1개, 25점)
   ↓
② 수험생이 독립적으로 답안 작성
   ↓
③ Telegram /grade 채점 및 확정 결과 기록
   ↓
④ ChatGPT가 문제 요구에 맞는 기술사 모범답안 작성
   ↓
⑤ 부족한 관련 지식·공학적 연결·답안 구조 보완
   ↓
⑥ /review 확인 및 완료 → 다음 문제
```

문제 유형에 따라 원리·비교·설계·현장 판단을 묶어 출제할 수 있지만, Topic Pack의 모든 Fact를 한 문항의 필수 요구로 간주하지 않는다.

## 2. 단계별 책임과 출력

| 단계 | 주체·입력 | 반드시 해야 하는 일 | 산출물 |
| --- | --- | --- | --- |
| ① 문제 출제 | ChatGPT; 기존 검토된 Topic Pack·사용자 요청 범위 | 원칙적으로 매회 **한 문제씩** 제시. 출제 문장은 실제 기술사형 서술 문제로 구성하고, 25점 기준을 밝힌다. 사용자 답안 전에는 모범답안·키워드 체크리스트·풀이 힌트를 선공개하지 않는다. | 문제 원문, Topic ID, 출제 시점의 근거/범위 |
| ② 답안 작성 | 수험생; 문제 원문 | 본인의 기억과 판단으로 답안을 완성한다. 사용자가 요청하지 않으면 작성 중 개입·정답 유도·자동 수정하지 않는다. 이미지/OCR 또는 텍스트는 비공개 제출 자료로 취급한다. | 원본 답안 |
| ③ 채점 | 기존 Telegram Bot `/grade` | 확정된 A/B/C/D/E 결과와 25점 총점, 요구사항별 판정 및 정성 피드백을 저장한다. ChatGPT의 후속 모범답안·지식 보완은 이전 점수를 **변경하지 않는다**. | 불변 채점 스냅샷·진단 |
| ④ 모범답안 | ChatGPT; 동일한 문제·Topic 근거·확정 채점 결과 | **서론 → 핵심 원리·정의 → 비교/수식/도해(필요한 경우) → 영향·설계 판단 → 대책·검증 → 결론**의 기술사 답안 구조로 작성한다. 문제에서 요구한 범위를 우선 충족하고, 단순 키워드 나열이나 과도한 지엽적 내용보다 물리적 사실·조건·인과관계를 우선한다. 출처 확인과 모델의 해설/추론을 구분하고 불확실한 기술 주장을 인증하지 않는다. | 검토 상태가 명시된 **학습용** 모범답안 |
| ⑤ 관련 지식 보완 | ChatGPT + 수험생; 원본 답안과 모범답안의 비교 | 부족점은 **누락된 요구, 부정확한 사실, 관련 개념 사이 논리, 현장 적용 판단, 답안 구성**으로 나누고 각 부족점마다 왜 필요한지·어떻게 연결되는지·필요한 보완 개념을 제시한다. 핵심만 대상으로 1회 복습 가능한 단위로 정리한다. | 보완 지식·자가 점검 질문·재작성 포인트 |
| ⑥ 복습 완료 | 수험생; Telegram `/review <topic_id>`, `/review done <topic_id>` | 학습용 모범답안, 이전 진단 및 보완 사항을 확인한다. 완료 기록은 수험생의 명시적 실행으로 남긴다. 필요하면 동일 Topic을 반복하되, 요청 없이 다음 문제를 한꺼번에 출제하지 않는다. | 개인별 복습 이력 및 다음 학습 주기 |

## 3. 채점 정책과 지식 권한은 그대로 유지

- **A 구조 3점 / B 요구 충족 6점 / C 사실 정확성 8점 / D 공학적 판단 6점 / E 연결성 2점, 총 25점**을 유지한다.
- **15점**은 문항 참고선이며 실제 시험의 문항별 합격 판정을 의미하지 않는다. 실전 목표선 17.5점, 고득점 기준 20점은 기존 안내값을 유지한다.
- A/B/C의 결정론적 권한, D/E에 대한 Argon 정성 제안과 프로그램의 최종 결정, fatal 및 보류 정책, Golden 및 Release Gate를 수정하지 않는다.
- 채점기에서 출력된 숫자를 ChatGPT가 자체 판단으로 덮어쓰거나 모범답안에 유리하도록 기존 답안을 재채점하지 않는다. 필요시 **채점기 결과와 ChatGPT의 별도 기술적 검토**를 명확히 구분한다.
- Topic Pack의 채점용 canonical Fact와 `rubrics/generated/`는 출제·복습의 결과로 자동 변경하지 않는다. 수정이 필요하면 정확한 원문·표준·물리적 근거와 범위 검증, 승인 절차, 회귀시험을 별도로 거친다.
- 비검증/차단 Fact Anchor를 필수 정답으로 자동 채택하지 않는다. 원문에서 확인되지 않은 지식은 확정 사실처럼 작성하지 않는다.

## 4. 문제·답안·채점·복습의 일관성

한 학습 주기의 논리적 식별자는 `topic_id`와 **문제 원문/ID**, 시도(Attempt)를 구별하는 비공개 식별자다. 동일 Topic에 서로 다른 문제가 있을 수 있다.

확정 채점의 피드백과 모범답안은 **해당 문제**에 연결한다. Topic에 존재하는 모든 심화 Fact를 해당 문제의 필수 항목으로 강제하지 않는다.

한 문제를 다시 작성해 재채점한 경우에는 이전 시도를 덮어쓰지 않고 새 시도로 비교한다. 점수 변화, 누락→충족 변화, 기술적 오류 수정 여부는 학습 진전 관찰에 사용하되, 모범답안의 점수 영향은 `none`이다.

원본 답안, 사진, OCR 텍스트, 채점 세션, Telegram chat ID, 학습 기록과 비공개 WordPress 본문·DB는 GitHub 공개 커밋에 올리지 않는다. 공개 학습 예제가 필요하면 비식별·합성 자료만 사용한다.

## 6. 학습용 모범답안 승인 경계

- ChatGPT 또는 Argon이 작성한 모범답안은 **학습용 초안**이며 기본 검토 상태는 `llm_reviewed_human_pending` 또는 동등한 검토 대기 상태다. 모델이 작성했다는 사실만으로 `human_verified`가 되지 않는다.
- 기술적 오류를 발견하면 **학습용 답안에서 명시적으로 정정**할 수 있으나, 원본 사용자 답안이나 확정 채점 이력을 조용히 바꾸지 않는다.
- 원문 자료 기반 내용·사용자 답안과의 비교·독립 문헌이나 제조사/표준 검증·ChatGPT의 공학적 추론을 구분한다. 참고자료가 지원하지 않는 내용을 출처에서 확인된 듯 표현하지 않는다.
- 학습용 자료의 `score_effect`는 반드시 `none`이다. 채점 근거로 승격할 때는 별도 검토·승인·빌드·회귀시험이 필요하다.

### 6.1 비공개 학습 DB의 오개념 교정 (2026-11-11)

- 사용자 답안과 문답에서 확인되는 오개념마다 문제·시도·Topic을 연결하고, 해당 근거 위치, 잘못 이해한 개념, 교정 설명과 적용 조건, 확인한 기술 출처, 자가 점검 질문, 검토 상태와 `score_effect: none`을 기록한다. 교정 설명은 올바른 개념이 왜 성립하고 현장에서 어떤 판단이 달라지는지 보여 준다.
- 답안에서 생략된 요구사항은 누락으로 기록한다. 의도가 모호한 표현과 AI가 추정한 오개념은 확인 대기로 둔다. 사용자가 이미 올바르게 설명한 부분은 교정 대상으로 집계하지 않는다.
- 같은 시도에서 같은 개념이 반복되면 한 교정 항목에 근거를 연결한다. 다음 답안이나 자가 점검으로 교정 여부를 확인하고 이력을 남긴다. 원본 답안과 확정 채점은 보존한다.
- 개인 교정 항목과 출처 원문은 비공개 영역에 저장한다. 공개된 글에 인용된 개인 답안·채점 내역에도 같은 기준을 적용한다. 개인 교정에서 발견한 일반 원리를 Topic Pack에 제안하려면 개인 이력을 제거하고 독립 근거로 검증한 뒤 Fact Anchor 적격성과 기존 승인 절차를 적용한다.

## 7. 개발·릴리스 운영 규칙

현재 복습 기능 개발은 `codex/review-question-answer-20261107` 브랜치에서 시작한다. 각 문제/Topic의 복습 자료는 가능한 작게 분리하여 PR로 검토·통합하며, 기존 채점 소스·운영 bank와 변경을 섞지 않는다.

학습 정책 문서 반영과 Telegram `/review` 기능 구현·배포는 별개 단계다. 구현 후에는 **복습 전후 확정 점수의 완전 동일성**, 다른 Topic에 대한 영향 없음, 기존 `/review done` 동작, 메시지 길이, 운영 배포 증거를 검증한다.

## 8. 주기 완료 판정

한 문제의 주기는 다음이 모두 확인되었을 때 완료된다.

1. 사용자 답안과 기존 Bot의 확정 채점 결과가 존재한다.
2. ChatGPT가 **그 문제에 맞는** 모범답안을 작성한다.
3. 채점 결과의 부족점을 겨냥한 관련 지식·논리 연결·현장 판단 보완이 제시된다.
4. 사용자가 복습을 확인하고 원한다면 `/review done`으로 완료를 기록한다.

채점기 결과가 없어도 학습용 답안을 작성할 수 있으나, 그 경우 위의 완전한 채점·복습 주기라고 보고하지 않는다.

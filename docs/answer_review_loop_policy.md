# Topic Pack, 내 답안, 비공개 학습 기록

> **사람용 핵심:** 표준 학습 순서는 독립 문제 작성 → Telegram 확정 채점 → 모범답안 확인 → 보완·복습입니다. 모범답안은 확정 점수나 Fact를 자동 변경하지 않습니다.
>
> **AI·개발자:** [코드·권한 참조](ai_implementation_reference.md) · [저장소 정책](../AGENTS.md). 날짜가 붙은 감사 결과는 당시 기록으로 유지합니다.


이 문서는 학습 순서와 데이터의 역할을 설명한다. 같은 주제를 가리키더라도 공개 채점 기준과 개인 답안·학습 기록은 따로 보관한다.

| 자료 | 무엇을 담는가 | 위치와 공개 범위 |
| --- | --- | --- |
| Topic Pack과 Fact Anchor | 검토된 공학 사실, 적용 조건, 출처, 문항 요구의 기준 | `rubrics/topic_packs/` — 공개 Git |
| Generated Bank | Topic Pack에서 생성한 운영 채점 자료 | `rubrics/generated/` — 공개 Git |
| 내가 쓴 답안과 확정 채점 | 제출 원문·이미지/OCR, 문제, 확정 `grade.json` | `data/sessions/<session_id>/` — 비공개 |
| 학습 이력 DB | 학습자·주제·문제·시도 ID, 점수, 요약 진단, 복습 상태 | 기본 `data/training_history.sqlite3` — 비공개 |
| WordPress 원문과 개인 학습 자료 | 출처 원문·OCR, 주제별 학습 자료 및 검토 기록 | 로컬 `data/` 등 — 비공개 |

## 어떻게 연결되는가

1. 검토된 Topic Pack은 문제의 주제와 **그 문제에서 실제로 요구한 내용**을 해석하고 채점할 때 쓰인다. Topic의 모든 Fact가 한 문제의 필수 답은 아니다. 채점에서 제외된 Anchor도 필수 정답으로 요구하지 않는다.
2. `/grade`는 원본 제출물을 비공개 세션에 보존한다. 문제와 답안의 경계가 불확실하면 채점하지 않고 확인을 요청한다. 채점이 완료되면 같은 세션에 확정 `grade.json`을 저장한다.
3. Bot은 확정 채점 **후에** 학습 DB에 시도 기록을 추가한다. `topic_id`로 Topic Pack과, `session_id`로 원본 세션과 연결한다. `question_id`는 문제를, `attempt_id`는 개별 시도를 구별한다. 이 연결은 코드에서 관리하며 DB의 외래 키로 강제되는 관계는 아니다.
4. 학습 DB에는 문제 글과 점수·진단 요약이 있지만 **원본 답안 전문이나 `grade.json` 전체를 저장하지 않는다.** 원본과 확정 결과를 확인하려면 해당 세션을 보아야 한다. 학습 DB 기록이 실패해도 이미 확정한 채점은 바뀌지 않는다.
5. `/review`는 Topic Pack에서 만든 읽기 전용 학습 자료와 개인 이력을 함께 보여준다. 제공된 학습용 모범답안과 같은 **문제**의 시도가 있을 때만 그 시도의 요구별 비교를 붙인다. 사용자가 직접 `/review`를 요청하면 아직 답안을 쓰지 않은 Topic의 기존 학습 자료도 볼 수 있다.

## 내가 공부하는 순서

**ChatGPT가 25점 문제 하나를 출제 → 내가 독립적으로 답안 작성 → Bot `/grade` 확정 채점 → ChatGPT가 같은 문제의 모범답안과 부족한 지식·논리·공학적 판단을 설명 → 내가 `/review`로 복습**한다. 답안 제출 전에는 모범답안이나 채점 힌트를 먼저 보여주지 않는다. 명시적으로 `/review`를 요청한 경우는 예외다.

문제별 모범답안은 실제 문제 요구를 먼저 충족하고, 검증된 Topic 사실에 근거해 원리·조건·수식·현장 판단을 설명한다. 출처에서 확인한 내용과 AI의 해설·추론을 구분한다. 복습에서는 누락된 요구, 사실 오류, 인과관계 및 공학적 판단의 빈틈을 짚고 자가 점검 질문을 제시한다. AI 작성 자료의 검토 상태를 표시하며 사람 검토로 오인하지 않는다.

Bot의 채점 배점 A/B/C/D/E = **3/6/8/6/2**, 확정 점수·판정·원본 답안은 후속 학습 설명 때문에 수정하지 않는다. 다시 답하면 새 시도로 남긴다. `/review done <topic_id>`는 사용자가 원할 때 복습 완료를 기록한다. 원본 답안·확정 점수와 같은 문제의 모범답안·보완 설명을 확인해야 한 학습 주기가 완성된다.

## 공개 채점 기준으로 옮길 때

- Topic Pack에는 개인 답안, 오개념, 점수, 긴 풀이 과정이나 추측을 넣지 않는다. 필요한 가정·단위·적용 한계와 출처를 갖춘 일반적인 공학 사실만 둔다.
- 개인 답안에서 일반화할 만한 새 사실을 발견해도 곧바로 채점 기준이 되지 않는다. 개인 정보를 제거하고 기존 Anchor와 중복·소유 관계를 확인한 뒤, 독립 근거와 적용 범위를 검토하여 **기존** Topic Pack 승인·검증 절차를 따른다.
- 학습용 모범답안, WordPress 학습 자료, 교정 기록은 `score_effect: none`이다. AI가 작성한 자료를 사람 검토 완료나 정규 채점 사실로 표시하지 않는다.

## 현재 구현 범위

Bot에는 시도·점수·요약 진단·복습 상태를 저장하는 DB와 Topic별 `/review`가 있다. **개인 오개념의 근거, 수식 유도, 교정·재확인 과정을 구조화해 저장하는 별도 DB 스키마는 아직 없다.** 그런 항목은 향후 기록할 때도 원본 증거, 오류와 단순 누락의 구분, 출처, 검토 상태를 남기고 채점과 분리해야 한다.

Bot이 `/grade` 직후 ChatGPT에게 **그 문제만의 새 모범답안을 자동 생성하게 하는 기능도 이 문서가 보장하지 않는다.** 현재 `/review`가 보여주는 기존 Topic별 학습 답안과, 학습 순서에서 ChatGPT가 작성하는 문제별 답안은 구별한다.

개인 세션·DB·WordPress 원문과 OCR·비공개 채점 결과·인증정보는 공개 Git에 올리지 않는다. 저장 위치와 백업 범위는 [데이터 인벤토리](data_reports_inventory.md), [비공개 운영 백업](private_runtime_backup.md)을 참고한다.

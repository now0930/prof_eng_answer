# 검토 대기 Topic Pack 제안

여기는 운영 채점에 포함되지 않는 편집 제안을 보존한다. `rubrics/topic_packs/`와 generated bank의 입력은 아니다.

- 신규 Topic 제안 5건: bubbler, 공압식 valve accessories, float level, guided wave radar, sight glass.
- 기존 force-balance 압력변환기 문구 개선 1건: 승인된 운영 source의 해시를 변경하지 않도록 별도 보존했다. `proposed_topic_sheet.md`도 이 제안에 속한다.

사람 검토 시 질문 단위·중복 소유권·필수 Anchor·출처·승인 상태를 확인한다. 새 Topic은 저장소의 `add-topic` → 검토 → `approve-topic` 절차를 거쳐 운영 경로로 이동한다. 기존 승인 Topic의 수정 제안도 실제 source 변경과 재검증을 별도로 수행한다. 이 디렉터리의 과거 메타데이터나 문장만으로 승인되었다고 간주하지 않는다.
